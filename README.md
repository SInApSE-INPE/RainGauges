# RainGauges

## Projeto 4: Desenvolvimento e Pesquisa dos Laboratórios Associados  
**Subprojeto:** Estudo sobre a estimativa e previsão de chuva via satélite meteorológico em cooperação com a NOAA e JAXA

---

## Objetivo do Projeto

Este subprojeto tem como objetivo desenvolver e implementar métodos computacionais para estimar, validar e prever sistemas associados à precipitação medida por sensores remotos. Alinha-se ao objetivo específico 1.6 (EO1.6), que busca desenvolver e implementar métodos para análise e modelagem de sistemas não lineares e complexos nas áreas de atuação do INPE.

Além disso, este subprojeto está relacionado ao M-14.3 do plano diretor atual do INPE, que visa “prover e aprimorar previsão numérica de tempo e de clima sazonal, e projeções de mudanças climáticas por meio de modelagem do sistema terrestre, bem como produtos meteorológicos derivados de satélites e radares, para órgãos setoriais, governamentais, instituições públicas e privadas, e para a sociedade em geral”. O foco principal é a utilização de produtos derivados de satélites para previsão do tempo.

---

## Conteúdo do Repositório

Este repositório contém os códigos associados ao projeto, incluindo:

- **Download de dados IMERG e GSMaP:** scripts para baixar dados satelitais diretamente das fontes oficiais.  
- **Análise estatística e validação:** códigos para comparar dados satelitais com dados observados, avaliando a qualidade dos produtos.  
- **Pré-processamento e homogenização:** ferramentas para preparar e uniformizar os dados satelitais antes da análise.
